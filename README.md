# 노노그램 🧩

가로·세로 숫자를 보고 숨은 그림을 찾는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `puzzles.js` + `game.js`)입니다.

- **규칙**: n x n 칸. 줄 옆 숫자는 그 줄에서 **이어서 칠할 칸 수**를 순서대로 말한다(`3 1` 은 3칸 칠하고 한 칸 이상 띄우고 1칸, 칠할 칸이 없는 줄은 `0`). 가로·세로 숫자를 모두 만족하면 완성. 칸은 비움 · 칠함 · ✕(칠하지 않을 칸) 세 가지
- **퍼즐 22개**: 5×5 열 개(쉬움), 10×10 여덟 개(보통), 15×15 네 개(어려움). 완성하기 전에는 이름과 그림이 숨겨져 있고, 완성하면 색이 입혀진 그림과 이름이 나온다
- **모두 찍지 않고 풀린다**: 줄 하나만 보고 알아내는 추리(`logic.js` 의 `solveLine` → `solveByLines`)를 되풀이하는 것만으로 모든 퍼즐이 끝까지 풀린다. 그림이 이런 퍼즐이 되도록 `tools/build.js` 가 초안(`tools/drafts.js`)을 검사하고, 안 풀리면 좌우 대칭을 지키며 칸을 한두 개 고쳐서 `puzzles.js` 를 만든다. 시험에서 **해가 하나뿐인지**도 확인한다
- 조작: 칸을 누르면 칠하고(다시 누르면 지움), **끌면** 한 줄을 한꺼번에(방향이 가로나 세로로 고정, 빈 칸에만 칠하고 지울 때는 처음 칸과 같은 표시만 지운다). **✕ 표시** 모드나 PC 오른쪽 클릭으로 ✕. 다 채운 줄의 숫자는 흐려진다. ↩ 되돌리기(Z, 한 번 끈 것이 한 단계) · 🔍 확인(C, 틀린 칸을 빨갛게, 무료) · 💡 힌트(H, 틀린 칸을 고쳐 주거나 칠할 칸 하나를 알려 줌, **기록 시간 +30초**) · 🔄 다시(R) · X 로 모드 전환
- 시간은 퍼즐을 푸는 동안(창이 보일 때)만 흐르고, **하던 퍼즐은 저장돼서** 이어서 할 수 있다(`nonoSave_<퍼즐>`). 퍼즐별 가장 빠른 기록과 깬 퍼즐은 `nonoDone`, 로비에는 깬 퍼즐 수(`nonogramCleared`)가 보인다
- 15×15 는 폰에서 칸이 작아(약 20px) 끌어서 칠하는 것이 편하다

규칙과 풀이는 `logic.js`(화면 없이 Node 로 시험), 퍼즐은 `puzzles.js`, 화면·입력·소리는 `game.js`. 시험은 `node --test`: `test/logic.test.js`(줄 풀이를 **모든 숫자·여러 부분 상태에서 완전 탐색과 대조**, 모순 검출, 모든 퍼즐의 크기·유일해·줄 풀이만으로 풀림, 되돌리기·완성 판정·힌트).
